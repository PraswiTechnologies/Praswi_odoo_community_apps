Inward Gate Pass on GRN (Receipts)

Security Gate Entry, Vehicle Tracking, Validation Lock & Printable Gate Pass PDF

Replace paper gate registers with structured inward gate entry tracking directly inside Odoo 20 Inventory Receipts (GRN). Record vehicle, driver, LR/bilty, and supplier challan details, enforce a pre-validation lock when required, and print a signed Inward Gate Pass PDF.

Key Highlights & Capabilities

  • Auto-sequenced Gate Pass No. (e.g., IGP/2026/0001) with one-click Generate Gate Pass and Mark Gate Out timestamps.
  • Dedicated Gate Pass tab capturing Vehicle No., Transporter, LR/Bilty No., Supplier Challan/Invoice No., Driver details, Security Officer, and Remarks.
  • Optional Settings toggle: Require Inward Gate Pass before GRN Validation to enforce Vehicle & Challan entry.
  • Printable QWeb PDF Inward Gate Pass with item quantities and signature blocks for Security, Driver, and Store In-Charge.
