Auto-Invoice on Delivery Validation

Instant Draft or Posted Customer Invoices When Warehouse Validates Delivery

Eliminate manual billing delays between warehouse dispatch and accounting. This module automatically triggers Customer Invoice creation when a Sales Order-backed Outgoing Delivery is validated—while safely respecting partial deliveries, backorders, and incoming returns.

Key Highlights & Capabilities

  • One-click toggle in Inventory → Configuration → Settings to auto-create Customer Invoices on SO delivery validation.
  • Optional Auto-Post Created Invoice toggle—leave unchecked to keep invoices in Draft for finance verification.
  • Uses Odoo's native sale.order._create_invoices() flow so prices, taxes, journals, and fiscal positions stay 100% standard.
  • Automatically skips incoming customer returns and deduplicates multi-delivery batch validations.
